# EMA_RSI_ST — change notes

Engine: `src/strategies/strategy1_sar_ema_rsi.js` · Routes: `emaRsiSt*.js` · Env prefix: `VIX_*` / core swing keys

Append a dated bullet whenever this strategy changes. Newest on top.

## Log
- 2026-08-11: Live now applies BOTH OI gates paper has always run — the awaited `checkLiveOi` on the candle-close entry path and the cached `checkCachedOi` on the intra-candle path — with the regime appended to the entry reason and `oiAtEntry` / `oiRegime` on the trade record. Backtest now measures the negative-candle stop in OPTION PREMIUM points (delta+theta model) instead of raw spot points, matching paper: a trade flat on spot but bleeding theta is red for paper and was not for the backtest. The legacy `EMA_RSI_ST_SL_MODE=candle` time-stop is mirrored in the backtest too (inert at the default `ema`).
- 2026-08-11: light-theme `.run-btn` colour on the Backtest page — the dark navy fill had no entry in the light skin's hex rewriter, so it stayed a dark-theme button on a light page. Now a solid blue button with a white label (5.2:1). Styling only.
- 2026-08-11: Live page no longer throws on an empty session — the trade-detail modal's click handler ran `getElementById('ltModal').addEventListener` unconditionally, but `#ltModal` is only rendered once `sessionTrades` is non-empty, so every fresh page load logged an uncaught TypeError and dropped the rest of that script block. Guarded. (Part of an app-wide dark/light + mobile UI pass; no strategy logic touched.)
- 2026-08-09: the held option contract is now streamed on the shared Fyers websocket (new `src/utils/optionFeed.js`) instead of this engine fetching it with its own repeated `getQuotes` poll — the premium the exit rules read updates per tick rather than once per poll interval, and the REST call only fires when the stream is quiet. The poll loop stays, as both the fallback and what renews the subscription lease, so `OPTION_SOCKET_FEED_ENABLED=false` (or a feed whose ticks carry no resolvable symbol) restores the previous behaviour exactly.
- 2026-08-08: stopSession now frees the capital-pool reservation unconditionally (`capitalPool.clear`) — its square-off is conditional on `currentBar` and wrapped in a try/catch, so a position could survive it and leave the broker pool permanently short.
- 2026-08-08: paper entries now report against the shared Zerodha capital pool (`src/utils/capitalPool.js`). Entry is synchronous and the premium only lands on the first option poll, so `qty × PAPER_CAPITAL_EST_PREMIUM` is blocked up front and corrected to the real premium there; released with the net P&L on exit. Advisory only — an unfundable entry is still taken and raises the Real-Time dashboard alert.
- 2026-08-07: `TRADE_RESOLUTION` moved out of the EMA_RSI_ST Settings section into **Instrument & Backtest** — it is now the single global candle timeframe for every strategy (no engine/logic change here; the same key, same value).
- 2026-08-06: Paper page no longer resurrects a PREVIOUS day's session on a trading day — the boot rehydrate's "last saved session" fallback (and the chart backfill that follows its trades' day) is now cleared unless today is a weekend/NSE holiday, so a restart with no trades yet shows today's empty session instead of yesterday's trades over yesterday's chart (new `src/utils/staleSessionGate.js`).
- 2026-08-05: Removed the 0DTE expiry-day guard entirely (Paper + Live) — no more `/start` refusal, `EXPIRY_DAY_0DTE` modal, or `?force=1` bypass. We trade intraday only, so same-day expiry is just a normal session; the block was optional risk friction. Dropped the detector helpers and the frontend confirm flow (`force` param gone from `handleStart`/`ltHandleStart`).
- 2026-08-05: Dropped the per-strategy expiry override — 0DTE guard now reads the common OPTION_EXPIRY_OVERRIDE only (all strategies share one intraday expiry). Removed EMA_RSI_ST_OPTION_EXPIRY_* from Settings.
